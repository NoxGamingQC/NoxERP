# NoxERP (in development)
Enterprise Resource Planning

## Planned

* 🛒 Point of Sale (POS) – Process sales and payments.
* 📦 Inventory – Track stock, transfers, and purchase orders.
* 👥 Employees – Scheduling, permissions, time tracking.
* 📊 Dashboard & Analytics – Sales, trends, KPIs.
* 👤 Customers – Profiles, loyalty programs, purchase history.
* 💰 Accounting – Revenue, expenses
* 🚚 Suppliers – Orders, receiving, vendor management.
* 🏬 Multi-location – Manage multiple stores, restaurants, or bars from one place.
* 🖥️ Desktop and mobile support
